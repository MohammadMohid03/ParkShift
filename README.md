# PARKSHIFT

PARKSHIFT is a Godot 4 mobile parking game with 100 precision-driving challenges across five districts. Choose a car, navigate a marked course, and park inside the target bay to earn stars and rewards.

The project uses GDScript, procedural 3D environments, touch and keyboard driving, saved progression, and Android export support.

## Technology

- Godot 4.7.2
- GDScript and Godot 3D
- Android ARM64 debug export
